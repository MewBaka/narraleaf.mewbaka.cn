---
title: "Video"
description: The `Video` element for full-screen video playback, covering preload, fades, playback control, and seeking.
---
<Callout type="warning">
    Beta feature, subject to change.
</Callout>

Video is an element that allows you to play a video.

The video is full-size of the player. 

```typescript
const video = new Video({
    src: "https://example.com/video.mp4",
    muted: true,
});

scene.action([
    video
        .show()
        .play()
        .hide(),
]);
```

## Chainable Methods

### preload

<Callout type="info">
    Available since `0.33.0`.
</Callout>

<Steps>
<Step>

Put the video element on the stage without showing it, so it starts buffering. The action resolves immediately, and does nothing to a video already on the stage.

Use it a few lines before the video is shown or played, so the first frame is ready when it is.

```typescript
video.preload();
```
</Step>
</Steps>

### show

<Steps>
<Step>

Show the video. Pass a `VideoFadeOptions` object to fade it in; the action waits for the fade to finish, and the fade starts once the clip can present a frame.

```typescript
video.show();
video.show({duration: 500, easing: "easeOut"});
```

- `options?: VideoFadeOptions` - `duration` in milliseconds and an optional `easing`. With no positive duration, the clip appears at once.
</Step>
</Steps>

### hide

<Steps>
<Step>

Hide the video. Pass a `VideoFadeOptions` object to fade out the current frame before the clip leaves the stage; the action waits for the fade to finish.

```typescript
video.hide({duration: 600});
```

- `options?: VideoFadeOptions` - `duration` in milliseconds and an optional `easing`. With no positive duration, the clip disappears at once.

A fade lands on its end state when skipped or fast-forwarded. Stepping back across a fade abandons it and restores the clip state recorded by the line stepped back to. Available since `1.1.0`.
</Step>
</Steps>

### play

<Steps>
<Step>

Play the video and wait for it to finish.

```typescript
video.play();
```
</Step>
</Steps>

### pause

<Steps>
<Step>

Pause the video, keeping its current position.

```typescript
video.pause();
```
</Step>
</Steps>

### resume

<Steps>
<Step>

Resume playback from the current position. Unlike `play`, this does not wait for the video to finish.

```typescript
video.resume();
```
</Step>
</Steps>

### stop

<Steps>
<Step>

Stop the video: pause it and end any pending `play()` so the story continues.

```typescript
video.stop();
```
</Step>
</Steps>

### seek

<Steps>
<Step>

- `time: number` - The time, in seconds, to seek to.

Seek to a specific time.

```typescript
video.seek(3);
```
</Step>
</Steps>
