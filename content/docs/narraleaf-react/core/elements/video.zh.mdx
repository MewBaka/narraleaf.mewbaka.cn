</Callout>

`Video` 用于在舞台上播放视频，占用整个舞台

```typescript
const video = new Video({
    src: "https://example.com/video.mp4",
    muted: true,
});

scene.action([
    video
        .show()
        .play()
        .hide(),
]);
```

## 链式方法

### preload

<Callout type="info">
    自 `0.33.0` 起可用
</Callout>

<Steps>
<Step>

将视频元素加入舞台但不显示，使其开始缓冲。动作立即完成；对已在舞台上的视频调用不会有任何效果

在显示或播放它的前几行调用，首帧就会在需要时已经就绪

```typescript
video.preload();
```
</Step>
</Steps>

### show

<Steps>
<Step>

显示视频。传入 `VideoFadeOptions` 可淡入；动作会等待淡入结束，并在视频能够呈现画面后才开始淡入

```typescript
video.show();
video.show({duration: 500, easing: "easeOut"});
```

- `options?: VideoFadeOptions` - 以毫秒计的 `duration` 与可选的 `easing`。没有正数时长时立即显示
</Step>
</Steps>

### hide

<Steps>
<Step>

隐藏视频。传入 `VideoFadeOptions` 可让当前画面淡出后再离开舞台；动作会等待淡出结束

```typescript
video.hide({duration: 600});
```

- `options?: VideoFadeOptions` - 以毫秒计的 `duration` 与可选的 `easing`。没有正数时长时立即隐藏

跳过或快进会直接进入淡入淡出的结束状态。回退越过一次淡变会放弃它，并恢复回退到的那一行记录的视频状态。自 `1.1.0` 起可用
</Step>
</Steps>

### play

<Steps>
<Step>

播放视频并等待完成

```typescript
video.play();
```
</Step>
</Steps>

### pause

<Steps>
<Step>

暂停视频，保留当前播放位置

```typescript
video.pause();
```
</Step>
</Steps>

### resume

<Steps>
<Step>

从当前位置继续播放。与 `play` 不同，不等待播放结束

```typescript
video.resume();
```
</Step>
</Steps>

### stop

<Steps>
<Step>

停止视频：暂停播放，结束任何等待中的 `play()`，让剧本继续推进

```typescript
video.stop();
```
</Step>
</Steps>

### seek

<Steps>
<Step>

- `time: number` - 跳转目标时间（秒）

```typescript
video.seek(3);
```
</Step>
</Steps>
