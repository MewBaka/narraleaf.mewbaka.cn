Studio はブループリントの一部を `.bp` 形式のテキストとして交換できます。ブループリントのコマンドラインツールと、グラフを読んだり書いたりする Agent も同じ形式を使います。

## Copy as Text

1 つ以上のノードを選び、右クリックメニューの **Copy as Text** を選びます。選択範囲はノードとその間のエッジを含むブループリントテキストとしてクリップボードに入ります。

## ブループリントテキストを貼り付ける

ファイル、チャットメッセージ、別の Studio ウィンドウからブループリントテキストをコピーし、キャンバスへ貼り付けます。Studio は配置前に検証します。

- 各ノード種別がこの Studio に存在する
- 各プラグインノードのプラグインが読み込まれている
- ピンとエッジが現在のノード宣言に合う
- プロジェクト項目への参照が解決できる

貼り付けが拒否された場合は理由が表示され、何も書き込まれません。成功した貼り付けは 1 回の元に戻す操作になります。

## 何が含まれるか

ブループリントテキストはグラフ構造、ノード引数、リテラルのピン値を含みます。プロジェクト文書、アセット、プラグインコードは含みません。アセット、キャラクター、ページ、プラグインを参照するグラフは、貼り付け先にも同じ項目が必要です。

完全な文法は Studio の `project/app/blueprint.md` ツール文書を参照するか、Agent にブループリント形式の章を読ませてください。
