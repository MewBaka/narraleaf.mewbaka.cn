title: 蓝图文本
description: 把选中的节点复制为蓝图文本，并把蓝图文本粘贴回画布
---

Studio 可以用 `.bp` 格式交换蓝图的一部分。蓝图命令行工具以及读取或写入蓝图的 Agent 也使用同一格式

## 复制为文本

选择一个或多个节点，打开右键菜单并选择**复制为文本**。选区会以蓝图文本写入剪贴板，包含节点以及节点之间的连线

## 粘贴蓝图文本

把来自文件、聊天消息或另一个 Studio 窗口的蓝图文本粘贴到画布。Studio 会在放置前校验文本：

- 每个节点类型必须存在于当前 Studio
- 插件节点所需的插件必须已加载
- 引脚与连线必须符合当前节点声明
- 对工程条目的引用必须能够解析

粘贴被拒绝时会说明原因，并且不写入任何内容。粘贴成功时，新增节点作为一步撤销写入

## 文本包含什么

蓝图文本携带图结构、节点参数和字面量引脚值。它不携带工程文档、资产或插件代码。图中引用的资产、角色、页面或插件必须在粘贴目标中存在

完整语法请阅读 Studio 的 `project/app/blueprint.md` 工具文档，或让 Agent 读取蓝图格式章节
