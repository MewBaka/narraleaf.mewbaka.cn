Dev Mode はディスク上のプロジェクトを別ウィンドウで実行します。正式ビルドと同じゲームランタイムを使うため、ページ移動、ストーリー実行、ブループリント実行、セーブ、プレイヤー入力をエディターのキャンバスではなくここで確認できます。

## 開始と停止

Dev Mode は次から開始できます。

- UI エディター右上の再生ボタン
- 上部バーの **Run** で **Dev Mode** を選ぶ
- **Develop** メニュー

もう一度 **Dev Mode** を選ぶとセッションを停止します。別のプロジェクトは同時に実行できますが、1 つのプロジェクトにつき Dev Mode セッションは 1 つです。

## 言語

プロジェクトに複数の言語がある場合、Run メニューに **Language** 行が表示されます。**Automatic** はプレイヤーが見る言語を使います。別の言語を選ぶと、プレイヤーの保存済み言語を変えずにそのセッションだけを切り替えます。

選んだ言語がプロジェクトから削除されると、次の実行はその言語がないと報告して開始を拒否します。別の言語か **Automatic** を選んでください。

## リロード

Dev Mode はプロジェクトのストーリー、インターフェース、キャラクター、ローカライズ、スクリプト、ブループリントデータ、アセットを監視します。変更があると実行をリロードし、可能な場合は実行中のシーン変数とセーブ変数を保ちます。

エディターのキャンバスはゲーム全体を実行しません。ページ移動、ストーリー進行、ウィジェットイベント、セーブはここで確認します。

## デバッグツール

Dev Mode のデバッグパネルは、シーンの先頭、選択した行、保存変数のスナップショットからストーリーを開始できます。実行中のストーリー、ブループリント実行、その実行が報告した問題を表示します。場所を持つ問題から Studio の対応する行を開けます。

## Agent が保持するセッション

Agent は Dev Mode を開いてプレイテストできます。そのウィンドウは既定で非表示・読み取り専用で、Agent が待機状態になると閉じます。作者は通知の **Take over** でセッションを使い、**Continue** で Agent に返せます。

Agent が Dev Mode を保持している間、作者のデバッグツールは読み取り専用です。引き継ぐと Agent のプレイテストは中断され、返すと Agent が続行できます。
