Dev Mode 从磁盘读取项目，并在独立窗口中运行。它使用与正式构建相同的游戏运行时，因此页面导航、剧情执行、蓝图执行、存档和玩家输入都在这里检查，而不是在编辑器画布中检查。

## 启动与停止

可以从以下位置启动 Dev Mode：

- 界面编辑器右上角的播放按钮
- 顶栏中选中 **Dev Mode** 的**运行**按钮
- **开发**菜单

再次选择 **Dev Mode** 会停止当前会话。不同项目可以同时运行；每个项目最多有一个 Dev Mode 会话。

## 语言

项目包含多种语言时，运行菜单中会出现**语言**一行。**自动**使用玩家会看到的语言。选择其他语言只改变本次运行的显示语言，不会修改玩家的存档语言。

如果选中的语言从项目中移除，下一次运行会报告缺少该语言并拒绝启动。请改选其他语言或**自动**。

## 重新加载

Dev Mode 会监听项目的剧情、界面、角色、本地化、脚本、蓝图数据和资产。发生修改时，运行会重新加载，并在可行时保留当前场景变量与存档变量。

编辑器画布不会执行完整游戏。页面导航、剧情推进、控件事件和存档应在这里检查。

## 调试工具

Dev Mode 调试面板可以从场景开头、选中的行或变量快照开始运行剧情。它会显示正在运行的剧情、蓝图执行情况，以及本次运行报告的问题。带有位置的问题可以直接在 Studio 中打开对应行。

## Agent 持有的会话

Agent 可以打开 Dev Mode 进行试玩。它打开的窗口默认隐藏、只读，并在 Agent 空闲时关闭。作者可以在提示中选择**接管**来使用会话，再选择**继续**交还给 Agent。

Agent 持有 Dev Mode 时，作者的调试工具为只读。接管会中断 Agent 的试玩；交还后 Agent 可以继续。
