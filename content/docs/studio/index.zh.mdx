NarraLeaf Studio 是用于制作视觉小说的桌面编辑器。一个项目保存一部作品的故事、角色、资产、界面和发行设置，这些内容都在 Studio 中编辑

<Callout type="info">
Studio 2.0 是 Team beta 系列。使用 beta 期间仍应保持项目处于版本控制或另行备份
</Callout>

Studio 2.0 新增舞台时间轴、从故事预览直接摆放对象、场景与单行历史、故事行批注、带引用的重命名、剧本文档、Dev Mode 语言选择、Agent 持有的 Dev Mode、蓝图文本复制粘贴，以及 Team 项目模型

## 项目包含的内容

| 内容 | 工具 |
| --- | --- |
| 故事、章节、场景和动作 | 故事 |
| 角色、形态和差分 | 角色 |
| 图片、音频及其他文件 | 资产 |
| 标题、设置、存档、历史、画廊等页面 | UI |
| 对话、选项、通知、NVL 等游戏 UI | UI |
| 页面、控件和游戏 UI 的行为蓝图 | UI |
| 源语言文本、翻译和审校状态 | 本地化 |
| 元数据、图标、依赖和项目设置 | 项目 |

这些内容全部写入项目目录。移动、备份和提交时都应把该目录作为一个整体

## 页面与游戏 UI

两者都在 UI 编辑器中制作，区别在于覆盖的范围

| 类型 | 内容 | 尺寸 |
| --- | --- | --- |
| 页面 | 标题、设置、存档等完整界面 | 创建页面时指定 |
| 游戏 UI | 对话、选项、通知、NVL 及其他舞台内容 | 项目的舞台尺寸 |

游戏 UI 按位置挂载，同一项目中每个位置只有一个活动界面

## 编辑与运行

画布用于排版。**开发模式** 在实际运行环境中运行项目，交互、蓝图执行和存档状态在这里检查。**正式构建…** 生成交付给玩家的文件

## 处理剧本

故事编辑器不只是一组行：

- **舞台时间轴**显示每一行执行后各对象的状态，并跟随选项分支
- **在舞台上摆放对象**可从预览中拖动和缩放角色或图片，并写回对应行
- **重命名与查找引用**会同步变量、标签、场景或角色的所有名称引用
- **场景历史与单行历史**恢复本机快照或某一行的旧版本，不改动版本控制
- **故事行批注**把审阅讨论留在对应的行上
- **剧本文档**导入 Word、Fountain 和电子表格，并导出 PDF 或 Word 剧本

## Studio 与 Team

团队项目保持与 NarraLeaf Team 服务器连接。服务器保存项目的当前文档、版本、批注、审阅、待办和制作记录。Studio 把修改发给服务器的文档内核，工作区会显示项目连接、角色和往返状态

部署、角色和 Web 控制台见 [NarraLeaf Team](/zh/docs/studio/team)
