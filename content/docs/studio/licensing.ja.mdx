このページでは、NarraLeaf Studio でゲームを制作・パッケージ化・配布する際のライセンスについて説明します。対象は NarraLeaf Studio 2.0.0 以降です。このページは各コンポーネントのライセンスを説明するものであり、ライセンス本文に代わるものではありません。両者が異なる場合は、ライセンス本文が優先されます。

## 概要

- Studio は無料で利用でき、ソースコードは [Mozilla Public License 2.0](https://github.com/NarraLeaf/NarraLeaf-Studio/blob/master/LICENSE)（MPL-2.0）で公開されています。
- Studio で制作したゲームは作者のものです。商用リリースに無料で利用でき、任意のサードパーティプラットフォームで販売できます。ライセンスの申請、料金の支払い、収益の分配は不要です。
- 書き出したゲームに含まれる NarraLeaf のコンポーネントとサードパーティのコンポーネントは、いずれも商用ゲームとともに配布できます。「アセットを暗号化」がオンのときに含まれるアセット保護コンポーネントも同様です。
- ゲームに NarraLeaf のクレジット、スプラッシュ画面、エンジンロゴを入れる必要はありません。Studio が書き出し時にゲームへ自動的に配置するライセンスファイルを残すだけで構いません。
- 例外：Live2D と Spine のサポート、サードパーティのプラグインとテンプレート、ご自身でインポートした素材は、それぞれの条件に従って別途ライセンスを取得する必要があります（[別途ライセンスが必要な場合](#別途ライセンスが必要な場合)を参照）。

## あなたの作品

Studio で作成したシナリオ、キャラクター、イラスト、音声、UI、その他のプロジェクトの内容は、あなた、または各権利者に帰属します。NarraLeaf はこれらに対していかなる権利も主張しません。

## 書き出したゲームに含まれる NarraLeaf のコンポーネント

| コンポーネント | 含まれる場合 | ライセンス |
| --- | --- | --- |
| ゲームランタイム、および作者が有効にした組み込みプラグイン（ギャラリー、メニューバー、クイックセーブ、テキストエフェクト） | 常に | MPL-2.0（NarraLeaf Studio リポジトリ由来） |
| NarraLeaf React エンジン（`narraleaf-react`） | 常に | MPL-2.0 |
| モバイルシェル（`@narraleaf/studio-shell`） | Android / iOS の書き出し | MPL-2.0 |
| アセット保護コンポーネント | 「アセットを暗号化」がオンのデスクトップ版（Windows、macOS、Linux） | NarraLeaf 独自ライセンス（後述） |

### MPL-2.0 がゲーム作者にとって意味すること

MPL-2.0 はファイル単位で適用されます。これらのコンポーネントをそのまま使う場合、シナリオ、素材、ご自身で書いたスクリプトは MPL-2.0 の対象にならず、クローズドソースの商用製品を含め、任意の条件で配布できます。上記コンポーネントのソースファイルを変更し、変更版を配布する場合に限り、変更したファイルを MPL-2.0 で公開する必要があります。

MPL-2.0 は、配布者に対して MPL ファイルのソースコードの入手方法を受領者に伝えることを求めています。Studio はゲームを書き出す際、同梱するサードパーティ通知の冒頭に、ゲームランタイムと含まれる組み込みプラグインのバージョン、ライセンス、対応するバージョンのソースコードの所在を記載します。NarraLeaf React エンジンも、ソースコードの所在とともに同じ通知に記載されています。そのため、これらのコンポーネントをそのまま使う場合は、この通知を残しておけば、ソースコードを別途提供する必要はありません。

### アセット保護コンポーネント

このコンポーネントはオープンソースではありません。NarraLeaf は、NarraLeaf Studio でゲームを制作するすべての作者に対し、このコンポーネントを Studio が書き出したままの状態で、Studio で制作したゲームとともに複製・配布する権利を、商用リリースを含め、全世界で、無償かつ収益分配なしで許諾します。それ以外の権利は許諾しません。「アセットを暗号化」をオフにして書き出したゲーム、および Web、Android、iOS の書き出しには、このコンポーネントは含まれません。

## サードパーティのコンポーネント

書き出したゲームに含まれるサードパーティのオープンソースコンポーネントのライセンスファイルは、Studio が自動的にゲームへ配置します。

- `THIRD-PARTY-NOTICES.txt`：ゲームに実際に含まれるすべてのオープンソースパッケージと、そのバージョン、ライセンス、ソースコードの所在、ライセンス本文を記載します。デスクトップ版では実行ファイルの隣、Web 書き出しではサイトのルートに置かれます。そのゲームに実際に含まれるものだけを記載し、たとえば Web 書き出しにはデスクトップ版でのみ使うコンポーネントは記載されません。
- デスクトップ版には、さらに `LICENSE.electron.txt`（Electron、MIT ライセンス）と `LICENSES.chromium.html`（Chromium とそのコンポーネントのライセンス）が含まれます。

これらのコンポーネントの多くは MIT、BSD、ISC、Apache などのライセンスを採用しており、共通の条件は著作権表示とライセンス本文をソフトウェアとともに配布することです。ゲームを配布する際は、これらのファイルを削除したり名前を変えたりせずに残してください。それ以外に、これらのライセンスはゲーム画面やスタッフクレジットでの表記を求めていません。

FFmpeg など Studio アプリケーション自体に同梱されるサードパーティ製ソフトウェアは Studio とともにインストールされるだけで、書き出したゲームには含まれません。[サードパーティライセンス](/ja/docs/studio/third-party-licenses)を参照してください。

## クレジット表記

Studio で制作したゲームを配布する際、スプラッシュ画面、タイトル画面、スタッフクレジットで NarraLeaf Studio や NarraLeaf React に言及する必要はなく、エンジンロゴを残す必要もありません。任意で表記していただくことはできますが、条件ではありません。

唯一の要件は、[サードパーティのコンポーネント](#サードパーティのコンポーネント)で説明したライセンスファイルを残すことです。なお、MPL-2.0 は NarraLeaf の名称やロゴを使用する権利を許諾するものではありません。

## 別途ライセンスが必要な場合

- **Live2D**：Studio は Live2D Cubism SDK を含まず、代わりにダウンロードすることもありません。Live2D キャラクターを使う場合は、SDK をご自身で Live2D 公式からダウンロードし、Live2D のライセンス条件に同意してください。Live2D を使ったゲームを商用リリースできるか、出版許諾契約が必要かどうかは、Live2D の条件に従います。導入方法は[モデルランタイム](/ja/docs/studio/model-runtimes)を参照してください。
- **Spine**：Studio は Spine ランタイムを含まず、代わりにダウンロードすることもありません。Spine アニメーションを使うには、有効な Spine ライセンスをご自身で保有し、Spine ランタイムライセンスの定めに従ってそのライセンス本文をゲームに同梱する必要があります。
- **サードパーティのプラグインとテンプレート**：プラグインストアと UI テンプレートストアのコンテンツは各作者が公開しており、それぞれのライセンスが適用されます。サードパーティのプラグインがゲームに同梱する依存関係は、Studio が生成する `THIRD-PARTY-NOTICES.txt` には記載されません。その説明はプラグイン作者の責任です。
- **インポートした素材**：画像、音声、動画、フォント、モデル、AI で生成したコンテンツについて、ゲームでの使用と配布がライセンス上許されているかを確認するのはあなたの責任です。
- **スケルトンテンプレートのサンプル素材**：背景と音声は CC0（パブリックドメイン提供）で、自由に使用できます。出典は Studio のインストールフォルダ内にあるテンプレートの `CREDITS.md` に記録されています。

## Studio 自体の改変と配布

NarraLeaf Studio は MPL-2.0 に従って改変・再配布できます。改変版を配布する場合、変更した MPL ファイルのソースコードを MPL-2.0 で公開する必要があります。アセット保護コンポーネントはオープンソースの対象外であり、ソースコードには含まれません。
