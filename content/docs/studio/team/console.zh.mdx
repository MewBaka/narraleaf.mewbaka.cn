---
title: Web 控制台
description: Team 用于项目、文件、版本、审阅、待办和管理的浏览器界面
---

`https://<服务器>:54080/console/` 是 Team 自带的界面。它使用与 Studio 相同的账号和证书，支持英文、中文和日文，也支持桌面与手机浏览器。

控制台目前是 beta。它读取项目内容并记录围绕项目的工作，不会成为场景、页面或蓝图的第二个编辑器。

## 登录与初始化

新服务器在 `/console/setup` 使用 `nlteam up` 打印的代码初始化。初始化后，控制台使用账号密码和 `HttpOnly` 会话 Cookie，最长三十天，连续七天未使用即结束。

每个账号可以列出登录过的 Studio 设备并结束任意一台。运维可以一次结束某个账号的全部设备。两步验证、SSO、API 令牌和密码重置链接都在这里管理。

## 控制台显示什么

| 区域 | 读取或修改 |
| --- | --- |
| 项目 | 账号有角色的全部项目、成员、文件和版本 |
| 工作台 | 服务器持有的文件与版本，以及行旁批注 |
| 批注与审阅 | 讨论、建议修改、审阅结论与批准 |
| 待办 | 项目待办、优先级、标签与完成它的版本 |
| 通知 | 提及、审阅、关注、反应和构建结果 |
| 制作 | 构建、分享链接、统计、本地化、词汇表、配音、路线图、模板与 Webhook |
| 管理 | 账号、策略、签名密钥、存储、备份、归档与审计筛选 |

## 项目设置

项目所有者可以在控制台中修改成员与角色、编辑区域、访问申请、分享链接、Webhook、保存与恢复权限、归档以及把项目移出列表。

运维可以跨服务器看到同样的项目设置，并管理账号、存储配额、备份与审计记录。

## 它不做什么

控制台不编辑项目内容，不运行 Studio，也不应用文档操作。内容修改仍由 Studio 通过 Team 文档内核完成。这样项目内容只有一个写入者，版本历史与冲突处理才保持可信。
