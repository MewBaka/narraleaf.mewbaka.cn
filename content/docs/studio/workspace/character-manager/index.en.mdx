The **Characters** panel holds the cast of a project. Characters can be placed in groups, tagged, and searched by name.

## Kinds

The kind is chosen when the character is created. The kinds share no data, and switching discards what the previous one held.

| Kind | Drawn from |
| --- | --- |
| **Preset sprites** | One finished image per named pose. A single-image character is one pose. |
| **Layered sprite** | Layers composited at run time and switched by tag, so one pose can move several layers at once. |
| **Live2D Cubism** / **Spine** / **Custom runtime** | A rigged model drawn by a runtime supplied with the project. See [Model Runtimes](/docs/studio/model-runtimes). |

## Preset and layered sprites

A preset character is a flat list of named poses, each backed by one image asset. The story addresses a pose by its name.

A pose can also be a **PNG frame sequence**: several PNG files played in order at a fixed frame rate. The frame-sequence card beside the pose list adds the files, sets the playback speed and loop count, and previews the result. The story still sees one pose.

A layered character stacks image layers on a shared canvas. Layers are grouped on axes, and a pose selects one option per axis, so a single pose can change several layers together.

## Names, aliases, and avatars

A character has one canonical name and any number of **aliases**. Story rows may name either, so an alias can carry a short form, a translated name, or a nickname the cast uses. Renaming the canonical name does not break rows that use an alias.

The dialogue avatar is separate from the stage sprite. It can use its own image, or a portrait cropped from one of the character's poses. **Auto-frame avatar** places the crop around the detected head; the crop can then be moved and sized by hand. **Auto-frame all dialog avatars** in the character list does the same for every character. The story outline also draws this avatar beside a scene's cast.

## Runtime-drawn characters

A model character needs two things: a drawing runtime, and a model to draw. With both set, Studio reads the model and fills in the motions, expressions, and skins it offers, which the story then addresses by name. The entry, size, and starting state are set in the editor.

Runtimes are not bundled with Studio. See [Model Runtimes](/docs/studio/model-runtimes) for what to install and under which terms.

## Groups and deletion

Groups organize the Characters panel and the speaker picker. A character can be moved between groups or left ungrouped. The speaker picker can show groups as submenus and remembers which groups are folded.

Deleting a character is recorded in the workspace history and can be undone. Until it is restored, story lines that name that character stop resolving.
