**Characters**（キャラクター）パネルには、プロジェクトに登場するキャラクターがまとめられています。キャラクターはグループに分けたり、タグを付けたり、名前で検索したりできます。

## 種類

種類はキャラクター作成時に選びます。各種類の間でデータは共有されず、切り替えると前の種類が保持していた内容は失われます。

| 種類 | 描画方法 |
| --- | --- |
| **Preset sprites**（プリセットスプライト） | 名前付きのポーズごとに 1 枚の完成画像を使用します。1 枚絵のキャラクターはポーズが 1 つだけです。 |
| **Layered sprite**（レイヤードスプライト） | 実行時に合成されるレイヤーをタグで切り替えます。1 つのポーズで複数のレイヤーを同時に変化させられます。 |
| **Live2D Cubism** / **Spine** / **Custom runtime**（カスタムランタイム） | プロジェクトに用意したランタイムが描画するリグ付きモデルです。詳細は [モデルランタイム](/ja/docs/studio/model-runtimes) を参照してください。 |

## プリセットスプライトとレイヤードスプライト

プリセット方式のキャラクターは、名前付きポーズをフラットに並べたリストで、各ポーズは 1 つの画像アセットに対応します。ストーリーはポーズをその名前で参照します。

ポーズは **PNG フレームシーケンス**にもできます。複数の PNG を決まったフレームレートで順番に再生します。ポーズ一覧の横にあるフレームシーケンスのカードでファイルを追加し、再生速度とループ回数を設定して、その場でプレビューできます。ストーリーから見ればシーケンス全体が 1 つのポーズです。

レイヤード方式のキャラクターは、共有のキャンバス上に画像レイヤーを重ねます。レイヤーは軸ごとにグループ化されており、ポーズは各軸につき 1 つの選択肢を選ぶため、1 つのポーズで複数のレイヤーをまとめて変化させられます。

## 名前、別名、アバター

キャラクターには正式な名前が 1 つと、任意の数の**別名**があります。ストーリーの行にはどちらも書けるため、別名は短い呼び方、翻訳名、作中での愛称などに使えます。正式名を変更しても、別名を使っている行は壊れません。

会話アバターはステージのスプライトとは別に設定します。専用の画像を使うことも、キャラクターのポーズから顔の部分を切り出すこともできます。**アバターを自動で切り抜く**と検出した頭部の周りに切り抜き枠が置かれ、その後も手動で位置と大きさを調整できます。キャラクター一覧の**すべてのアバターを自動で切り抜く**は、すべてのキャラクターに同じ処理を行います。キャラクターエディターで立ち絵を追加または差し替えると、絵が変わったアバターは自動で切り抜かれます。手動で調整した切り抜き枠と、個別に設定したアバター画像はそのまま残ります。ストーリーのアウトラインでも、シーンに登場するキャストの横にこのアバターが表示されます。

## 登場時の既定値

登場時の既定値は、キャラクターが登場するときの立ち絵の大きさと立ち位置を決めます。登場行に書かれていない拡大率や位置などはここに従い、行に書かれた項目はその項目だけを上書きします。

キャラクターエディターで立ち絵を追加または差し替えると、Studio が登場時の既定値を設定します。

- 立ち絵のピクセルサイズが同じキャラクターがいる場合は、その拡大率と基準線を共有し、二人の身長差を保ちます。
- それ以外の場合は、画像内の人物の実際の位置に合わせて構図を決め、頭部検出で全身と半身を見分けます。頭頂はステージ上端から少し余白を空けます。人物の下に透明な余白がある全身の立ち絵は、頭から約 8 割を表示します。人物が画像の下端に届いている立ち絵（作者が切り揃えたもの）は、その下端をステージの下端に合わせます。半身の立ち絵は全体が下端に立ちます。

置き換えるのは Studio が計算した値だけで、手動で調整した既定値はそのまま残ります。プレビューではドラッグで配置と拡大縮小ができ、会話ウィンドウの位置は色付きのブロックで示されます。**標準の構図を適用**は現在の立ち絵で構図を決め直します。メニューの**「名前」に合わせる**は、立ち絵が同じサイズのキャラクターの設定を共有します。

## ランタイム描画のキャラクター

モデル方式のキャラクターには、描画用のランタイムと、描画対象のモデルという 2 つが必要です。両方を設定すると、Studio はモデルを読み取り、それが提供するモーション、表情、スキンを取り込みます。ストーリーはこれらを名前で参照します。エントリ、サイズ、初期状態はエディタで設定します。

ランタイムは Studio に同梱されていません。何をどのような条件でインストールする必要があるかは、[モデルランタイム](/ja/docs/studio/model-runtimes) を参照してください。

## グループと削除

グループはキャラクターのパネルと話者選択の両方を整理します。キャラクターはグループ間で移動したり、どのグループにも属さない状態にしたりできます。話者選択ではグループをサブメニューとして表示でき、折りたたんだグループも記憶されます。

キャラクターの削除はワークスペースの履歴に記録され、元に戻せます。復元するまでの間、そのキャラクターを名指ししているストーリーの行は解決できなくなります。
