## 类型

角色类型在创建时选定。各类型之间没有共享数据，切换会丢弃前一种持有的内容

| 类型 | 绘制来源 |
| --- | --- |
| **成品差分** | 每个具名姿态一张成品图；单图角色即只有一个姿态 |
| **分层立绘** | 在运行时合成、按标签切换的图层，一个姿态可以同时改变多个图层 |
| **Live2D Cubism** / **Spine** / **自定义运行时** | 由随项目提供的运行时绘制的绑定模型，参见[模型运行时](/zh/docs/studio/model-runtimes) |

## 成品差分与分层立绘

成品差分角色是一组具名姿态，每个姿态对应一张图片资产，故事按姿态名称调用

一个姿态也可以是 **PNG 帧序列**：多张 PNG 按固定帧率依次播放。姿态列表旁的帧序列卡片用于添加文件、设置播放速度和循环次数，并直接预览结果。对故事来说整个序列仍是一个姿态

分层立绘角色把图层叠放在同一张画布上。图层按轴分组，一个姿态在每条轴上各选一个选项，因此一个姿态可以同时改变多个图层

## 名称、别名与头像

角色有一个正式名称和任意多个**别名**。故事行可以写正式名称或任一别名，因此别名可以承担简称、译名或剧中昵称。修改正式名称不会让使用别名的行失效

对话头像与舞台立绘分开设置。头像可以使用独立图片，也可以从角色的某个姿态裁出头像。**自动截取头像**会把裁剪框放在检测到的头部周围，之后仍可手动移动和缩放。角色列表中的**自动截取全部对白头像**会对所有角色执行同样的操作。剧情大纲也会在场景出场角色旁显示这张头像

## 由运行时绘制的角色

模型角色需要两样东西：绘制运行时，以及要绘制的模型。两者就位后，Studio 会读取模型，填入它提供的动作、表情和皮肤，故事按名称调用。入口、尺寸和初始状态在编辑器中设置

运行时不随 Studio 分发。需要安装什么、适用哪些条款，参见[模型运行时](/zh/docs/studio/model-runtimes)

## 分组与删除

分组同时用于整理角色面板和说话人选择器。角色可以在分组之间移动，也可以不属于任何分组。说话人选择器可以把分组显示为子菜单，并记住哪些分组处于折叠状态

删除角色会记入工作区历史，可以撤销。在恢复之前，故事中引用该角色的行无法解析
