---
title: Story comments
description: Discuss a story row in a thread, mark the thread as a to-do or resolved, and find every thread in the Comments panel.
---

A comment thread belongs to one story row. Each reply records its author and time, and the thread can be marked as a to-do or resolved.

## Start a thread

Right-click a row and choose **Add comment**. Enter the first message and press <kbd>Ctrl</kbd>+<kbd>Enter</kbd> or <kbd>Cmd</kbd>+<kbd>Enter</kbd> to send it.

A row with a thread shows a speech-bubble mark at its right edge. Select the mark to read or reply. An unresolved thread uses the warning colour; a resolved thread stays as a quiet mark so it can still be found.

## Comments panel

The **Comments** panel lists every thread by scene. Filter by:

- open
- to-do
- resolved
- author

Select a thread to open its row. A thread follows the row when the row moves. If the row is deleted, the thread remains under **Rows not found**.

## Storage and attribution

Comments are stored in the project and synchronised by version control. They are not part of the game and are not counted as story text.

A comment is signed with the Team account the project is signed in with. A project without a Team account uses the author name set under Settings → Version control.
