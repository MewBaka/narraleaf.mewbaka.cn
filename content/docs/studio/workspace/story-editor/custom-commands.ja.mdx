カスタムコマンドは、数行の演出コマンドを 1 つの名前で保存したものです。保存すると、ストーリーエディタで組み込みコマンドと同じように入力できます。例：`@左右に揺れる Anyo 強さ=10`

## コマンドを作成する

方法は 2 つあります。

- 左サイドバーの **…** メニューを開いて **カスタムコマンド** を選び、**新規コマンド** を選びます。
- ストーリーエディタで数行を選び、右クリックして **カスタムコマンドとして保存** を選びます。元の行はそのまま残ります。

コマンドはタブで開きます。上部の情報カードで **名前** と **説明** を入力します。説明はコマンドメニューに表示されます。名前には空白、引用符、`/ @ # < > =` を使えず、数字で始めることも、組み込みコマンドやプロジェクト内の他のコマンドと同じ名前にすることもできません。

下の行はストーリーエディタと同じ書き方です。行を選ぶとその場で編集でき、最後の行を選ぶか入力を始めると行が追加されます。

## 引数を宣言する

値の位置に `<引数名>` と書くと引数になります。

| 書き方 | 意味 |
| --- | --- |
| `xoffset=<強さ>` | 呼び出し時に指定した値 |
| `xoffset=-<強さ>` | 指定した値の符号を反転した値 |
| `d=<時間=0.1>` | 既定値のある引数。呼び出し時に省略できる |

引数の種類は書いた位置と同じです。数値は同じ単位と範囲、選択肢は同じ候補を持ち、キャラクターの位置はキャラクターだけを受け付けます。1 つの引数を複数の行で使えます。情報カードには各引数の種類と、必須か既定値ありかが表示されます。

## コマンドを呼び出す

ストーリー行で `@` を入力すると、コマンドメニューの **カスタム** 分類にプロジェクトのカスタムコマンドがすべて並びます。選ぶと、Studio が引数を順に尋ねます。

- 既定値のない引数は必須です。省略した行は下書きとして表示されます。
- コマンドを編集すると、それを呼ぶすべての行の再生内容が変わります。
- コマンドの名前を変えても、それを呼ぶ行はそのまま動きます。

## 使えるコマンド

カスタムコマンドには舞台、音、待機、変数のコマンドと、他のカスタムコマンドを入れられます。台詞、ジャンプ、フローのコマンドは使えません。

## 共有する

コマンドのタブ、または一覧の右クリックメニューから：

- **テキストとしてコピー** はコマンドをクリップボードにコピーします。チャットや文書にそのまま貼り付けられます。
- **ファイルに書き出す** はコマンドをファイルとして保存します。

どちらも、呼び出している他のカスタムコマンドを一緒に書き出します。別のプロジェクトでは、一覧上部の **コマンドを読み込む** を選び、**クリップボードから** または **ファイルから** を選びます。同じ名前のコマンドがある場合は番号が付き、読み込んだコマンド内の呼び出しも新しい名前に追従します。

共有はクラウドを経由しません。テキストやファイルにすべての内容が含まれます。

## 再生できない呼び出し

次の場合、呼び出し行は何も再生せず、**プロジェクトチェック** がその行にエラーを表示します。

- コマンドが削除された
- 必須の引数がない
- コマンドが直接または他のコマンドを通じて自分自身を呼ぶ
