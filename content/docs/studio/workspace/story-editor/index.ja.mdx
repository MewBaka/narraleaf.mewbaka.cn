**Story**（ストーリー）パネルには、スクリプトが収められています。1 つのプロジェクトは複数のストーリーを持つことができ、そのうち 1 つが既定のストーリーです。各ストーリーには入口となるシーンがあります。

## 構造

| 階層 | 内容 |
| --- | --- |
| Story（ストーリー） | チャプター。プロジェクトごとに 1 つのストーリーが既定になります。 |
| Chapter（チャプター） | 順序付けられたシーン。 |
| Scene（シーン） | 実際に再生される行。そのうち 1 つのシーンがストーリーの入口です。 |

シーンを削除すると、その中の行も一緒に削除され、そのシーンを対象とするジャンプは解決できなくなります。チャプターを削除すると、その中のシーンもすべて削除されます。

## シーンエディタ

シーンはタブとして開き、行のリストとして編集します。1 行は台詞、またはディレクション（画像の表示、音声の再生、カメラの移動、変数の設定、分岐など）のいずれかです。

- 行内で `/` を入力すると、キーボードから手を離さずにディレクションを挿入できます。設定の **「@」でアクションの作成を開く** をオンにすると `@` でも同じ操作ができます。システム言語が簡体字中国語の場合は既定でオンです。
- **Reading density**（表示密度）と行フィルタで、画面に表示するシーンの量を調整できます。フィルタは台詞のみを表示することもできます。
- **Find in scene**（シーン内を検索）は、開いているシーン内を検索します。大文字と小文字の区別、単語単位、正規表現のオプションがあり、一致した箇所を置換できます。
- 存在しないアセットを参照している行や、キャラクターのモデルにない名前を使っている行は、その場でマークされます。

行のコンテキストメニューから変数、ラベル、シーン、キャラクターの名前を変更し、書き込む前に変わるすべての参照を確認できます。[名前の変更と参照の検索](/ja/docs/studio/workspace/story-editor/rename-references)を参照してください。

## シーンの説明

シーンには、Studio で名前の下に表示される説明を付けられます。シーンの用途、素材の出所、残っている作業を記録するためのもので、ゲームには表示されません。往復形式のスクリプトでは同じ説明を `#description` ヘッダーに保存し、`#description none` で消去します。

## ステージにオブジェクトを配置する

これには 2 つのディレクションが必要です。**Image**（画像）、**Text**（テキスト）、**Ambience**（環境演出）はオブジェクトを宣言します。ディレクションはオブジェクトに名前を付け、ソースを与え、開始位置に配置します。**Show**（表示）でオブジェクトを表示するまでは何も現れず、**Hide**（非表示）で再び取り除かれます。どちらもオブジェクトを名前で指定します。

**Layer**（レイヤー）は例外です。レイヤーは、それを作成するディレクションの時点から表示された状態で存在します。

表示する数行前にオブジェクトを宣言しておくと、画像やクリップも事前に読み込まれるため、実際に表示される瞬間が読み込み開始の瞬間と重ならなくなります。

**Ambience** も、ステージ上のほかのオブジェクトと同じく、そのシーンに属します。あるシーンで表示したオーバーレイは、別のシーンへジャンプすると止まります。雨を降らせたいシーンでは、そのシーン自身で表示してください。行内の名前を Ctrl キーを押しながらクリックすると、宣言元のディレクションが開きます。

キャラクターや画像を表示・移動する行にカーソルを置くと、プレビューでオブジェクトや角をドラッグして、その行の配置を書き換えられます。[ステージ上でオブジェクトを配置する](/ja/docs/studio/workspace/story-editor/stage-placement)を参照してください。

Ambience オーバーレイの**Show**には、独自の不透明度と速度を指定でき、その回の表示にのみ適用されます。

**Project check**（プロジェクトチェック）は、一度も表示されないオブジェクトを**Unshown stage object**（未表示のステージオブジェクト）として報告します。

## 動画を再生する

動画をステージに出すのは **Play**（再生）だけです。**Play** のディレクションは動画ファイルと名前を指定し、動画を表示して再生し、終わるとフェードアウトしてステージから取り除きます。後の行はこの名前で動画を指定します。**Pause**（一時停止）、**Resume**（再開）、**Seek**（シーク）、**Stop**（停止）、**Hide**（非表示）です。同じ名前で再び **Play** すると、その動画を最初から再生します。

**Play** の行の設定は次のとおりです。

- **Wait for the video**（再生の終了を待つ）：既定でオン。動画が終わってからストーリーが進みます。プレイヤーはクリックかスキップキーで動画を途中で終えられます。オフにするとストーリーはすぐに進み、動画は後の行の下で再生されます。セリフを進めるクリックで動画は中断されません。
- **Hide when finished**（再生の終了後に隠す）：既定でオン。オフにすると、**Hide** で取り除くまで動画は最後のフレームで止まります。
- **Exit**（退場）と時間：ステージを離れるとき、動画はフェードアウトするか、即座に切り替わります。
- **Muted**（消音）：音を出さずに再生します。

**Stop** は、動画を最後まで再生したものとして扱います。その後は **Play** の行の設定に従ってフェードアウトするか、現在のフレームで止まります。

動画ファイルはシーンの開始時から読み込まれるため、**Play** の行の前に宣言は必要ありません。

**Project check** は、終了を待つ **Play** の後で同じ動画を一時停止・再開・シーク・停止する行を、**Video already finished**（再生を終えた動画）として報告します。

## ストーリーからページを開く

**Open page**（ページを開く）行は、プロジェクトのページをステージの上に開き、そのページが **Close This Layer**（このレイヤーを閉じる）で自分を閉じるまでストーリーを待たせます。閉じたときの結果は、シーン変数、セーブ変数、永続変数のいずれかに書き込めます。値は変数の型に変換され、結果なしで閉じた場合（Back を含む）は変数を変更しません。

ページにはパラメータが渡されないため、各パラメータは既定値を使います。この行より前へ巻き戻すとページは閉じます。コマンド表記は `/page <ページ> [into=<変数>]` で、`/overlay` と `/popup` も別名として使えます。

## カスタムコマンド

よく使う数行の演出コマンドは、引数付きのカスタムコマンドとして保存し、`@` メニューの **カスタム** 分類から呼び出せます。例：`@左右に揺れる Anyo 強さ=10`。コマンドを編集すると、それを呼ぶすべての行が変わります。コマンドはテキストとしてコピーするか、ファイルに書き出して他のプロジェクトと共有できます。[カスタムコマンド](/ja/docs/studio/workspace/story-editor/custom-commands)を参照してください。

## ステージタイムライン

下部ドックの **Stage Timeline** は、現在のシーンの各行を実行した後のステージを表示します。オブジェクトごとに 1 本のレーン、行ごとに 1 列です。列を選んで対応する行へ戻り、別の選択肢分岐を追い、タイムラインをズームできます。[ステージタイムライン](/ja/docs/studio/workspace/story-editor/stage-timeline)を参照してください。

## レビューと履歴

コメントはストーリー行に属し、行と一緒に移動します。返信、ToDo、解決済み状態を持つスレッドを作れ、**Comments** パネルがすべてのスレッドをシーン別に一覧します。[ストーリー行のコメント](/ja/docs/studio/workspace/story-editor/comments)を参照してください。

ローカルのシーンスナップショットはバージョン管理の外に以前の内容を保存します。比較、復元、1 行の過去の版の確認については[シーン履歴と行履歴](/ja/docs/studio/workspace/story-editor/scene-history)を参照してください。

## 分岐と変数

選択肢、条件、ジャンプは、シーン内のディレクションとして記述します。Story flow（ストーリーフロー）は、その結果生じるシーン間の分岐をグラフとして表示します。

選択肢には `[hide if <条件>]` を 1 つ、`[disable if <条件>]` を 1 つ付けられます。隠された選択肢は提示されず、無効な選択肢は表示されますが選べません。インスペクターの **隠す条件** と **選べなくする条件** がこれらに対応します。以前の `show if` と `enable if` は拒否されます。

変数はストーリーから宣言・参照され、そのスコープによって値がどれだけ保持されるかが決まります。詳細は [変数](/ja/docs/studio/blueprint/variables) を参照してください。

## スクリプト

シーン単位、またはストーリー全体を、プレーンテキストファイルとして書き出し、読み戻すことができます。

| モード | 用途 |
| --- | --- |
| **Round-trip**（往復） | Studio の外で編集する場合。ファイルにはシーンのデータが含まれ、再度インポートできます。 |
| **Review**（レビュー） | 読解や差分の確認向け。文章のみで、インポートはできません。 |

**Import Script…**（スクリプトをインポート…）は、round-trip 形式のファイルをプロジェクトに読み込みます。複数行のプレーンテキストをシーンに貼り付けると、行ごとに分割するかどうかを確認されます。

Word、Fountain、CSV、TSV、XLSX の脚本をシーンとして取り込み、読みやすい PDF または Word の脚本として書き出すこともできます。[スクリプト文書](/ja/docs/studio/workspace/story-editor/script-documents)を参照してください。
