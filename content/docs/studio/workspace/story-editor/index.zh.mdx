**故事**面板存放剧本。一个项目可以包含多个故事，其中一个是默认故事；每个故事都有一个入口场景

## 结构

| 层级 | 内容 |
| --- | --- |
| 故事 | 章节。项目中有一个故事为默认故事 |
| 章节 | 按顺序排列的场景 |
| 场景 | 实际播放的行。其中一个场景是故事的入口 |

删除场景会一并删除其中的行，跳转到该场景的指令将无法解析。删除章节会删除其中的全部场景

## 场景编辑器

场景以标签页打开，内容按行编辑。一行要么是一句对话，要么是一条演出指令——显示图片、播放音频、移动镜头、设置变量、分支等

- 在行内输入 `@` 或 `/` 可直接插入演出指令，无需离开键盘
- **阅读密度**和行筛选决定一屏显示多少内容，筛选可以只显示对话
- **在场景中查找**在当前场景内搜索，支持区分大小写、全词匹配和正则表达式，并可替换匹配项
- 引用了缺失资产，或使用了角色模型中不存在的名称的行，会就地标出

可以在行的右键菜单中为变量、标签、场景或角色更名，并在写入前查看所有将改变的引用。见[重命名与查找引用](/zh/docs/studio/workspace/story-editor/rename-references)

## 场景说明

场景可以带一段显示在名称下方的说明，用于记录场景用途、素材来源或仍待处理的内容。游戏不会显示这段文字。往返剧本在 `#description` 头中保存同一段说明，`#description none` 会清除它

## 把东西放上舞台

需要两条演出指令。**图片**、**文本**、**氛围特效**声明一个对象：指令给它命名、给它来源、并把它放在起始位置。在**显示**之前什么都不会出现，**隐藏**则把它收回去。两者都按名称定位对象

**图层**是例外。图层从创建它的那条指令起就是可见的

在显示前几行先声明，它的图片或片段也会提前加载，出现的那一刻就不再是开始加载的那一刻

**氛围特效**和舞台上的其他对象一样，属于它所在的场景。在一个场景里显示的叠加层，跳转到别的场景时随之停止；需要下雨的场景要自己显示。按住 Ctrl 点行上的名称，就会打开声明它的那条指令

光标位于显示或移动角色、图片的行时，可以在预览中拖动对象或其角柄，改写该行的位置与尺寸。见[在舞台上摆放对象](/zh/docs/studio/workspace/story-editor/stage-placement)

氛围特效的**显示**行可以带自己的不透明度与速度，仅对本次显示生效

**项目检查**会以**未显示的舞台对象**报告没有任何一行显示的对象

## 播放视频

视频只由**播放**放上舞台。一条**播放**指令给出视频文件和名称，显示视频并播放，结束后淡出离开舞台。之后的行用这个名称指定它：**暂停**、**继续**、**跳转进度**、**停止**与**隐藏**。用同一个名称再次**播放**，会从头播放这个视频

**播放**行的设置：

- **等待播放结束**：默认开启，视频结束后故事才继续。玩家可点击或按跳过键提前结束视频。关闭后故事立即继续，视频在之后的行下面播放，点击推进对白不会打断视频
- **播放结束后隐藏**：默认开启。关闭后视频停在最后一帧，直到**隐藏**将其收回
- **退场**与时长：视频离开舞台时淡出，或直接切换
- **静音**：播放视频时不出声音

**停止**使视频按播放到结尾处理：随后按播放行的设置淡出，或停在当前帧

视频文件从场景开始就提前加载，播放行无需提前声明

**项目检查**会以**已播放完毕的视频**报告在等待播放结束的**播放**之后，对同一视频**暂停**、**继续**、**跳转进度**或**停止**的行

## 从故事打开页面

**打开页面**行会在舞台上方打开项目的页面，并等待该页面用**关闭本叠加页面**关闭自己。该行可以把页面关闭时带回的结果写入场景、存档或持久变量；结果会转换成变量的类型。页面没有返回结果时，包括用返回关闭，变量保持原值

页面不接收参数，页面参数使用默认值。回退到该行之前会关闭页面。命令写法为 `/page <页面> [into=<变量>]`，也接受 `/overlay` 与 `/popup` 别名

## 舞台时间轴

底部面板中的**舞台时间轴**按执行顺序显示当前场景每一行后的舞台：每个对象一条轨道，每一行一列。可以选择一列跳回对应行、切换选项分支或缩放时间轴。见[舞台时间轴](/zh/docs/studio/workspace/story-editor/stage-timeline)

## 审阅与历史

批注属于故事行，并随行移动。一条行可以带有回复、待办标记与已解决状态，**批注**面板按场景列出全部线程。见[故事行批注](/zh/docs/studio/workspace/story-editor/comments)

本机场景快照在版本控制之外保存之前的场景内容，可以比较、恢复，或查看某一行过去的版本。见[场景历史与单行历史](/zh/docs/studio/workspace/story-editor/scene-history)

## 分支与变量

选项、条件和跳转都作为演出指令写在场景中。故事流程图以图的形式显示场景之间的分支

一个选项可以带一个 `[hide if <条件>]` 子句和一个 `[disable if <条件>]` 子句。隐藏的选项不会出现，禁用的选项会显示但无法选择。它们对应属性检查器中的**隐藏条件**与**禁用条件**。旧写法 `show if` 与 `enable if` 会被拒绝

变量在故事中声明和读取，其作用域决定值能保留多久，参见[变量](/zh/docs/studio/blueprint/variables)

## 剧本文件

单个场景或整个故事都可以导出为纯文本文件，并可再导入回来

| 模式 | 用途 |
| --- | --- |
| **往返** | 在 Studio 之外编辑。文件携带场景数据，可以再导入 |
| **审阅** | 阅读与比对。只含正文，无法导入 |

**导入剧本…**把往返模式的文件读回项目。将多行纯文本粘贴到场景中时，Studio 会提示按行拆分

Studio 也可以把 Word、Fountain、CSV、TSV 和 XLSX 剧本导入为场景，并导出为可读的 PDF 或 Word 剧本。见[剧本文档](/zh/docs/studio/workspace/story-editor/script-documents)
