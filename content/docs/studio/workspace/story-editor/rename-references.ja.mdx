---

名前の変更は、変数、ラベル、シーン、キャラクターに使えます。旧名を参照している場所を書き換え、変更内容を先に一覧し、承認した変更を 1 回の元に戻す操作として適用します。

次の右クリックメニューから開けます。

- **Variables** パネルの行
- 変数、ラベル、シーン、キャラクターを参照するストーリー行
- **Story** パネルのシーン
- **Characters** パネルのキャラクター

## プレビュー

プレビューは変更をシーンごとにまとめ、変更前と変更後を表示します。チェックを外した場所は変更されません。**Rename** はチェックした変更を一度に書き込み、1 回の元に戻す操作ですべて戻せます。

次の内容が書き換わります。

- 変数宣言、ラベル、シーン名、キャラクター名
- 代入、条件、ループ条件、選択肢条件、インライン値の中の名前
- 名前を変更したラベルへ移動する `goto` 行
- キャラクターの名前変更時、旧名で話しているがまだキャラクターに結び付いていない行

id で変数、シーン、キャラクターを指す行とブループリントノードは自動的に追従し、書き換えは不要です。プレビューでは別に一覧されます。翻訳は変更不要です。既に使われている名前と式言語の予約語は選べません。

## 参照の検索

Variables パネルの変数の横にある矢印を開くと、その読み取り位置と書き込み位置が表示されます。各項目にはシーンと行があり、選ぶとその場所が開きます。

参照の検索は名前変更と同じ参照モデルを使います。宣言の名前が変わっても、id で指している参照は同じ対象に解決され続けます。
