Studio はエディター外の執筆ツールとストーリーを交換できます。取り込みはシーンを作成し、書き出しはレビュー、収録、保管用の読みやすい文書を作ります。

## 取り込み

**Import Script…** は次に対応します。

| 形式 | 拡張子 |
| --- | --- |
| Word | `.docx` |
| Fountain | `.fountain`、`.spmd` |
| 表計算 | `.csv`、`.tsv`、`.xlsx` |

Studio はファイルを読み、話者を決める貼り付けウィザードを開きます。Word の見出し、Fountain のシーン見出し、シーン列の変化が新しいシーンを開始します。

- 表計算では、話者、セリフ、メモ、シーンが入る列を指定します
- 話者のない行は地の文になります
- メモはセリフの後のメモ行になります
- 新しいシーンはストーリーに追加され、1 回の元に戻す操作でまとめて削除できます

ウィザードは書き込む前に、追加、変更、削除するすべての行を一覧します。元文書を書き出した後に Studio で編集したシーンは、取り込み時にその編集が上書きされます。ウィザードは先にそのことを示します。

## 書き出し

出力するシーン、話者、内容を選びます。1 人の話者に絞ると、その話者のセリフと、文脈として直前のセリフが含まれます。

| 形式 | 用途 |
| --- | --- |
| PDF | 閲覧、レビュー、印刷 |
| Word（`.docx`） | 編集と共同作業者への受け渡し |

書き出し内の行 id はボイス収録用スクリプトと同じ id です。書き出した脚本と収録テイクを対応付けられます。
