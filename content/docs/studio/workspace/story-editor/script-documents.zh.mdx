Studio 可以与编辑器之外的写作工具交换故事内容。导入会创建场景，导出会生成用于审阅、配音或归档的可读文档

## 导入

**导入剧本…**支持：

| 格式 | 扩展名 |
| --- | --- |
| Word | `.docx` |
| Fountain | `.fountain`、`.spmd` |
| 电子表格 | `.csv`、`.tsv`、`.xlsx` |

Studio 先读取文件，再打开粘贴向导确定每个说话人。Word 中的标题、Fountain 中的场景标题或场景列的变化会开始一个新场景

- 电子表格需指定说话人、台词、备注和场景各在哪一列
- 没有说话人的行成为旁白
- 备注成为台词之后的备注行
- 新场景添加到故事中，撤销一次即可移除

向导会在写入前列出将要新增、修改和删除的每一行。源文档导出后又在 Studio 中修改过的场景，导入时这些修改会被覆盖，向导会先说明

## 导出

选择要包含的场景、角色与内容。只筛选一个角色时，导出内容包含该角色的台词，并以前面的台词作为上下文

| 格式 | 用途 |
| --- | --- |
| PDF | 阅读、审阅与打印 |
| Word（`.docx`） | 编辑与交给协作者 |

导出中的行 id 与配音录音稿使用同一套 id，因此可以把导出的剧本与录音条目对应起来
