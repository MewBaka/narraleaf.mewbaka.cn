title: デザインの読み込み
description: Figma、Photoshop、画像で描いた画面を UI エディタにページやゲーム UI として読み込み、ボタンやダイアログをそのまま使えるようにする
---

ほかのツールで描いた画面は、UI エディタのページとして読み込めます。**インターフェース**パネルで**デザインを読み込む**をクリックし、Figma の書き出しファイル、PSD、または 1 枚以上の画像を選びます。

| 読み込み元 | 読み込まれる内容 |
| --- | --- |
| **Figma** | [NarraLeaf Studio Export](https://www.figma.com/community/plugin/1707010640966969953) プラグインで書き出したフレーム。フレーム、グループ、長方形はコンテナに、オートレイアウトは表現できる場合スタックに、テキストはテキストに、ベクターとマスクは画像になります。 |
| **PSD** | グループはコンテナに、各レイヤーは Photoshop で描かれた位置の画像になります。クリッピングされたレイヤーと描画モードを使うレイヤーは所属するレイヤーに結合され、非表示のレイヤーは読み込まれません。 |
| **画像** | 選んだ画像は 1 つのページにまとめて読み込まれます。いちばん大きい画像と同じ大きさの画像はそれに揃い、小さい画像は中央に置かれるので位置を調整します。 |

ページはプロジェクトの解像度に合わせて拡大縮小され、画像は画像アセットの新しいフォルダに入ります。読み込み後、Studio は PSD のレイヤースタイルなど簡略化した内容を、関係するレイヤー名とともに一覧で表示します。

画像に描き込んだ文字は翻訳できません。ボタンの文字は画像の上にテキストとして置いてください。

## Figma プラグイン

**NarraLeaf Studio Export** は [Figma コミュニティ](https://www.figma.com/community/plugin/1707010640966969953)からインストールします。ブラウザ版でもデスクトップ版でも使えます。プラグインにはネットワークへのアクセス権がなく、ダウンロードするファイル以外は何もコンピューターの外に出ません。

<Steps>
<Step>

### フレームを選ぶ

書き出すフレーム、またはその中の任意のレイヤーを選択します。何も選択しない場合は、ページ上のトップレベルのフレームがすべて一覧に表示されます。

</Step>
<Step>

### 書き出す

右クリックして **プラグイン › NarraLeaf Studio Export › Export and check…** を選び、フレームにチェックを入れて **Export** をクリックします。すべての画像を含む `.narraleaf-figma.json` ファイルが 1 つ得られます。

</Step>
<Step>

### 読み込む

Studio の**インターフェース**パネルで**デザインを読み込む**をクリックし、そのファイルを選びます。読み込みダイアログには、各フレームと、それがページとゲーム UI のどちらとして読み込まれるかが表示されます。

</Step>
</Steps>

| Figma | Studio |
| --- | --- |
| フレーム、コンポーネント、インスタンス、セクション、グループ | コンテナ（塗り、線、角丸、影、クリッピングを保持） |
| オートレイアウト | スタックコンテナ。スタックで表現できない場合は元の位置に配置 |
| 画像で塗りつぶした長方形 | 画像 |
| テキスト | テキスト。フォントはファミリー名でプロジェクトのフォントアセットと照合されます。文字間隔は保持されず、混在したスタイルは最初の部分のスタイルになります |
| ベクター、ブーリアン、マスク、描画モード | 2 倍の画像として元のレイヤーの位置に正確に配置 |
| 非表示のレイヤー | 読み込まない |

レイヤー名に `[raster]` を付けると、どのレイヤーでも画像として書き出せます。

## 状態のあるボタン

状態ごとにボタンを描くと、操作できる 1 つのボタンとして読み込まれます。

- **PSD または Figma**：状態を 1 つのグループにまとめ、`normal`、`hover`、`pressed`、`disabled`（またはノーマル、ホバー、プレス、無効）と名前を付けます。同じグループのテキストレイヤー 1 つがボタンの文字になります。
- **Figma コンポーネント**：状態プロパティ（`State = Default / Hover / Pressed / Disabled`）を持つコンポーネントセットのインスタンスはボタンになります。
- **画像**：`start.png`、`start_hover.png`、`start_pressed.png` という名前のファイルは 1 つのボタンになります。

## ゲーム画面

ゲーム実行中の画面のデザインは、ページではなくゲーム UI として読み込めます。フレームのトップレベルのグループに、属するゲーム UI に合わせてダイアログ、選択肢、クイックメニュー、通知（または `dialog`、`choice`、`quick menu`、`notification`）と名前を付けると、読み込みダイアログがそのフレームに**ゲーム UI** を選び、置き換えられる既存のゲーム UI を一覧にします。元に戻すと 1 回で復元できます。グループの外のレイヤー（背景や立ち絵など）は読み込まれません。

| 部分 | 読み取り方 |
| --- | --- |
| **ダイアログ** | 「セリフ」と名付けたテキストは本文に、「名前」と名付けたテキストは話者の名前に、「アバター」と名付けたレイヤーは話者のアバターになります。名前が専用のグループに入っている場合、そのグループはキャラクターが話している間だけ表示されます。名前を付けていない場合は、最も大きいテキストがセリフに、その上のテキストが名前になります。 |
| **選択肢** | 最初に描いた選択肢が選択肢リストの行になり、その中のテキストが選択肢の文字に、2 つ目の選択肢との間隔が行間になります。 |
| **クイックメニュー** | オート、スキップ、ログ、セーブ、ロード、設定、非表示（または `auto`、`skip`、`log`、`save`、`load`、`config`、`hide`）と名付けたボタンはそれぞれの機能を実行します。ログ、セーブ、ロード、設定は同じ名前のプロジェクトのページを開きます。「オン」（または `on`）と名付けた状態は、オートとスキップの実行中に保つ見た目になります。 |
| **通知** | 最初に描いたメッセージが通知リストの行になります。 |

### Figma でレイヤーにマークを付ける

レイヤー名を手で変える代わりに、プラグインでマークを付けられます。レイヤーを選択して右クリックし、**プラグイン › NarraLeaf Studio Export** から次のコマンドを選びます。

- **Mark as Game UI**：Dialogue box、Choices、Quick menu、Notifications
- **Mark dialogue part**：Line、Speaker name、Avatar
- **Mark quick-menu button**：Auto、Skip、Log、Save、Load、Config、Hide
- **Clear mark**

Figma のプラグインメニューはアプリの言語に合わせられないため、各項目は中国語と英語で表示されます。プラグインのパネル上部の **Mark as…** リストでも同じ操作ができ、パネルは閉じません。

マークはレイヤー名より優先されます。Figma が自動で付けた名前（`Group 12` など）は役割の名前に変わり、自分で付けた名前は残したまま先頭に役割が付きます（`Dialogue box · Bottom panel` など）。マークを外すと、その後レイヤー名が変更されていなければ元の名前に戻ります。1 つのフレームには各ゲーム UI と、セリフ、名前、アバターがそれぞれ 1 つだけなので、2 つ目のレイヤーにマークを付けると 1 つ目のマークは外れます。

### チェックリスト

書き出す前に、プラグインのパネルには各ゲーム画面について Studio がどう読み込むかが表示されます。

- 各ゲーム UI がどのレイヤーになるか
- どのレイヤーがセリフ、名前、アバターになるか、そしてそれがマーク、名前、位置からの推測のどれによるものか
- オートとスキップに `on` の見た目があるか
- 選択肢リストでいくつの選択肢が見つかったか
- 足りないもの、および読み込まれないレイヤー

項目をクリックすると、キャンバス上でそのレイヤーが選択されます。チェックリストは Studio の読み込みと同じ規則で判定するので、表示される内容がそのまま読み込みの結果になります。プロジェクトにログ、セーブ、ロード、設定のページがあるかどうかは Studio でしかわからないため、読み込み後に知らせます。
