title: 导入设计稿
description: 将 Figma、Photoshop 或图片中绘制的画面导入界面编辑器，成为页面或游戏界面，按钮和对话框直接可用
---

在其他工具中绘制的画面可以导入为界面编辑器中的页面。在**界面**面板中点击**导入设计稿**，再选择 Figma 导出文件、PSD 或一张及以上的图片

| 来源 | 导入结果 |
| --- | --- |
| **Figma** | 用 [NarraLeaf Studio Export](https://www.figma.com/community/plugin/1707010640966969953) 插件导出的画框。画框、编组和矩形成为容器，自动布局在可表达时成为堆叠容器，文本仍是文本，矢量和蒙版导入为图片 |
| **PSD** | 编组成为容器，每个图层按 Photoshop 中的位置导入为图片。剪贴图层和使用混合模式的图层合并到所属图层，隐藏图层不导入 |
| **图片** | 所选图片导入到同一个页面。与最大图片尺寸相同的图片与其对齐，较小的图片居中放置，需手动调整位置 |

每个页面按项目分辨率缩放，其中的图片存入图片资产中新建的文件夹。导入完成后，Studio 会列出所有经过简化的内容并指明涉及的图层，例如未导入的 PSD 图层样式

画在图片里的文字无法翻译，按钮文字应作为文本放在图片上方

## Figma 插件

从 [Figma 社区](https://www.figma.com/community/plugin/1707010640966969953)安装 **NarraLeaf Studio Export**。网页版和桌面版 Figma 都能使用。插件没有联网权限，除了你下载的文件，任何内容都不会离开你的电脑

<Steps>
<Step>

### 选择画框

选中要导出的画框，或画框中的任意图层。什么都不选时，插件会列出当前页面的所有顶层画框

</Step>
<Step>

### 导出

右键选择**插件 › NarraLeaf Studio Export › 导出并检查…**，勾选画框后点击**导出**，得到一个 `.narraleaf-figma.json` 文件，所有图片都打包在里面

</Step>
<Step>

### 导入

在 Studio 的**界面**面板中点击**导入设计稿**并选择该文件。导入对话框会列出各个画框，以及每个画框导入为页面还是游戏界面

</Step>
</Steps>

| Figma | Studio |
| --- | --- |
| 画框、组件、实例、分区、编组 | 容器，保留填充、描边、圆角、阴影和裁切 |
| 自动布局 | 堆叠容器；无法用堆叠表达时按原位置摆放 |
| 填充了图片的矩形 | 图片 |
| 文本 | 文本。字体按字体族名匹配项目中的字体资产；字间距不保留，混合样式取第一段的样式 |
| 矢量、布尔运算、蒙版、混合模式 | 2 倍图片，精确覆盖在原图层的位置 |
| 隐藏图层 | 不导入 |

在图层名中加上 `[raster]`，可将任意图层导出为图片

## 带状态的按钮

每个状态各画一份，导入后就是一个可交互的按钮

- **PSD 或 Figma**：将各状态放在同一个编组里，分别命名为 `normal`、`hover`、`pressed`、`disabled`（或普通、悬停、按下、禁用），同组中的一个文本图层作为按钮文字
- **Figma 组件**：带「状态」属性的组件集实例（`State = Default / Hover / Pressed / Disabled`）导入为按钮
- **图片**：名为 `start.png`、`start_hover.png`、`start_pressed.png` 的文件合成为一个按钮

## 游戏画面

游戏运行时的画面设计可以导入为游戏界面，而不是页面。将画框的顶层编组按所属的游戏界面命名为对话框、选项、快捷菜单或通知（或 `dialog`、`choice`、`quick menu`、`notification`），导入对话框就会为该画框选择**游戏界面**，并列出将被替换的现有游戏界面，撤销一次即可恢复。编组之外的图层（例如背景、立绘）不导入

| 部分 | 识别方式 |
| --- | --- |
| **对话框** | 命名为「台词」的文本成为句子，命名为「名字」的文本显示说话人名字，命名为「头像」的图层显示说话人头像。名字单独放在一个编组中时，该编组只在有角色说话时显示。未按上述命名时，最大的文本作为台词，其上方的文本作为名字 |
| **选项** | 画出的第一个选项成为选项列表的行，其中的文本显示选项文字，与第二个选项的间距决定行距 |
| **快捷菜单** | 命名为自动、跳过、日志、存档、读档、设置、隐藏（或 `auto`、`skip`、`log`、`save`、`load`、`config`、`hide`）的按钮执行对应功能。日志、存档、读档、设置打开项目中同名的页面。命名为「开启」（或 `on`）的状态是自动和跳过运行期间保持的外观 |
| **通知** | 画出的第一条消息成为通知列表的行 |

### 在 Figma 中标注图层

不必手动改名，可以直接用插件标注。选中图层后右键，在**插件 › NarraLeaf Studio Export** 中选择

- **标为游戏界面**：对话框、选项、快捷菜单、通知
- **标为对话框部件**：台词、名字、头像
- **标为快捷菜单按钮**：自动、跳过、日志、存档、读档、设置、隐藏
- **清除标注**

Figma 的插件菜单无法跟随界面语言，所以每一项都以「中文 / English」的形式显示。插件面板顶部的**标为…**列表也能完成同样的操作，而且不会关闭面板

标注优先于图层名称。Figma 自动命名的图层（例如 `Group 12`）会改为对应的名称；自己命名的图层保留原名，并在前面加上身份，例如「对话框 · Bottom panel」。清除标注时，如果图层之后没有改过名，会恢复原来的名称。同一个画框里，每种游戏界面以及台词、名字、头像各只能有一个，标注第二个图层时，标注会从第一个图层上移走

### 确认清单

导出之前，插件面板会在每个游戏画面下列出 Studio 的识别结果

- 每种游戏界面对应哪个图层
- 哪些图层是台词、名字和头像，以及它们是标注的、按名字认出的，还是按位置推测的
- 自动和跳过是否有「开启」状态
- 选项列表识别出几个选项
- 缺少什么，以及哪些图层不会导入

点击某一项即可在画布上选中对应图层。清单使用的识别规则与 Studio 导入时相同，所以清单上写的就是导入的结果。项目中有没有日志、存档、读档、设置页面只有 Studio 知道，导入完成后会提示
