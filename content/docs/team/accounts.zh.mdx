title: 账号与访问权
description: 创建 Team 账号、授予项目角色或区域模板，并收回访问权
---

每个账号都由运维创建，没有公开注册。第一个账号用 `nlteam init` 创建；之后运维可以在 Web 控制台创建账号，或使用 `nlteam user create`。

## 登录

Studio 通常通过浏览器使用 OAuth 与 PKCE 登录。没有浏览器的机器使用设备码流程，在 `/console/device` 输入代码。

服务器可以要求两步验证、要求 SSO、签发 API 令牌并发送密码重置链接。早于浏览器登录的 Studio 版本仍可使用密码登录。

每个登录的 Studio 都是一个设备。账号所有者可以在控制台结束设备，运维可以一次结束某个账号的全部设备。Studio 2.0 会把当前账号显示在标题栏，服务器离线时仍会保留。

## 创建账号

在服务器上：

```sh
printf '%s' 'their password' | nlteam user create bob --root /srv/team
```

在已经以运维身份登录的机器上：

```sh
nlteam login team.example.com:54080 ada < password.txt
printf '%s' 'their password' | nlteam user create bob --server team.example.com:54080
```

密码从标准输入读取，不放在参数里。运维也可以直接签发登录令牌：

```sh
nlteam token mint bob --server team.example.com:54080
```

## 运维

`admin` 组管理账号、项目、设置、签名密钥、存储和备份。`nlteam init` 会把第一个账号放进这个组。

```sh
nlteam user grant-admin bob --server team.example.com:54080
nlteam user revoke-admin bob --server team.example.com:54080
```

控制台可以编辑、锁定和删除账号。最后一名运维不能移除自己的访问权。

## 项目角色与区域

访问权按项目划分。每个成员只有一个角色：

| 角色 | 可以 |
| --- | --- |
| 所有者 | 修改项目设置与成员，编辑全部区域，按项目设置保存或恢复版本，并把项目移出列表 |
| 编辑者 | 编辑获准的区域，并在项目允许时保存或恢复版本 |
| 审阅者 | 阅读、批注并参与审阅，不能修改项目内容 |
| 查看者 | 阅读并记录自己账号允许的协作内容，不能修改项目内容 |

所有者或运维可以在控制台的项目设置中修改成员，也可以通过 `projects.members.set` 与 `projects.members.remove` 修改。`nlteam` 目前还没有修改成员的命令。

编辑者可以限制在剧情、角色、资产、界面、本地化或游戏配置。Team 不认识的路径按游戏配置处理，因此新类型的文件默认受保护。恢复版本会改动所有区域，需要全部六项权限。

权限模板提供现成的角色与区域组合：所有者、编辑者、作者、译者、美术、工程、审阅者和查看者。项目也可以接受访问申请，由所有者或运维决定。

## Studio 2.0 显示什么

账号没有角色的项目不会出现。启动器会标记团队项目，并把服务器设置保存在项目之外。角色为只读时 Studio 会明确显示，状态栏也会显示与服务器的往返状态。

## 服务器上的 Studio 设置

Studio 登录 Team 服务器后，**设置 → 传输**会提供**备份到 Team**与**从 Team 恢复**。备份携带与导出的设置文件相同的设置文档。恢复会先检查并预览，确认后才修改。

服务器可以因账号策略、文档过大或版本不支持而拒绝操作；每种拒绝都有对应的说明。

## 收回访问权

修改项目角色，或移除成员。要停止整个账号，使用：

```sh
nlteam user disable ada --server team.example.com:54080
nlteam user revoke-tokens ada --server team.example.com:54080
```

**`disable`** 停用账号，并拒绝再次登录。**`revoke-tokens`** 拒绝已经签发的全部令牌，但允许账号用同一密码重新登录。两者都在 Studio 的下一次调用生效。

<Callout type="warning">
已经建立的项目数据连接由版本控制服务器检查，直到仓库令牌过期；默认是十五分钟。要更快结束，需要先轮换签名密钥，再撤下旧密钥，而这会让所有人重新登录。
</Callout>

被停用的账号可以用 `nlteam user enable ada` 恢复。控制台也可以临时锁定或删除账号。

## 查看现有内容

```sh
nlteam user list --server team.example.com:54080
nlteam project list --server team.example.com:54080
nlteam status --server team.example.com:54080
nlteam audit --refused --server team.example.com:54080
```

`audit` 从新到旧读取访问决定。`--refused` 只显示拒绝记录。控制台用筛选器显示同一份记录，并提供账号与存储管理。
