A Team project keeps collaboration beside the content it discusses. The Studio workspace and the web console read the same threads, versions and records.

## Comments and suggested edits

A story row can carry a thread with replies, a to-do mark and a resolved state. The thread follows the row when it moves. If the row is deleted, the thread remains under **Rows not found**. See [Story comments](/docs/studio/workspace/story-editor/comments).

A comment can carry a suggested edit for the row. The author can apply the suggestion or continue the discussion without changing the scene.

## To-dos, reviews and approvals

- **To-dos** belong to a project, have a priority, and may be finished by a commit or a saved Team version
- **Reviews** request a review of one or more versions and record the verdict
- **Approvals** record that a milestone or change was accepted
- **Asset and language requests** ask the project for a file or a new language, and can be answered from the import flow

Viewers keep their own to-dos private. Reviewers can read and discuss without editing project content.

## Locks and presence

An **asset lock** keeps other authors from changing a file while one person replaces or edits it. The locked asset says who holds it and why. Presence shows who else has the project open and which story or Blueprint they are editing.

In a live session, authors share cursors, chat in the session and can follow another author's view. These live signals are separate from the server-held project documents.

## Notifications and discussion

Notifications cover comments, mentions, reviews, to-dos, approvals, watches, reactions and build results. A project has a chat and discussion area; an account can follow a thread or a project and receive email digests or push notifications.

## Production record

The server can keep and display:

- builds uploaded from the build report
- share links for a build
- project statistics
- localization and glossary work
- voice records
- roadmap items and milestones
- project templates
- webhooks and their delivery history

The web console reads these records across projects. Project content still changes in Studio.
