---
title: Web コンソール
description: プロジェクト、ファイル、バージョン、レビュー、ToDo、管理を行う Team のブラウザ画面
---

`https://<サーバー>:54080/console/` は Team 自身の画面です。Studio と同じアカウントと証明書を使い、英語、中国語、日本語に対応し、デスクトップでもスマートフォンでも使えます。

コンソールはベータです。プロジェクト内容を読み、周辺の作業を記録しますが、シーン、ページ、ブループリントを編集する第二のエディターではありません。

## サインインとセットアップ

新しいサーバーは `/console/setup` で、`nlteam up` が表示するコードを使ってセットアップします。その後はアカウントのパスワードと `HttpOnly` セッション Cookie を使い、最長 30 日、7 日間使われなければ終了します。

各アカウントはサインインした Studio デバイスを一覧し、任意のデバイスを終了できます。管理者は 1 つのアカウントの全デバイスを終了できます。2 段階サインイン、SSO、API トークン、パスワード再設定リンクもここで管理します。

## コンソールが表示するもの

| 領域 | 読み取りまたは変更 |
| --- | --- |
| プロジェクト | アカウントが役割を持つすべてのプロジェクト、メンバー、ファイル、バージョン |
| ワークベンチ | サーバーが保持するファイルとバージョン、行の横のコメント |
| コメントとレビュー | スレッド、変更提案、レビュー結論、承認 |
| ToDo | プロジェクトの ToDo、優先度、ラベル、完了したバージョン |
| 通知 | メンション、レビュー、ウォッチ、リアクション、ビルド結果 |
| 制作 | ビルド、共有リンク、統計、ローカライズ、用語集、ボイス、ロードマップ、テンプレート、Webhook |
| 管理 | アカウント、ポリシー、署名キー、ストレージ、バックアップ、アーカイブ、監査フィルター |

## プロジェクト設定

プロジェクト所有者はコンソールでメンバーと役割、編集領域、アクセス申請、共有リンク、Webhook、保存・復元の権限、アーカイブ、一覧からの削除を変更できます。

管理者はサーバー全体で同じプロジェクト設定を見て、アカウント、ストレージ容量、バックアップ、監査記録を管理します。

## 行わないこと

コンソールはプロジェクト内容を編集せず、Studio を実行せず、ドキュメント操作を適用しません。内容変更は Studio が Team のドキュメントカーネルを通して行います。プロジェクト内容の書き手を 1 つに保つことで、バージョン履歴と競合処理の信頼性を維持します。
