---
title: NarraLeaf Team
description: A self-hosted server for Studio 2.0 team projects, their versions, roles and collaboration record.
---

NarraLeaf Team is a server an organization runs itself. It holds the projects a team works on, decides who may reach each one, keeps their documents and versions, and serves its own web console alongside Studio.

Studio 2.0 treats a team project differently from a local project. The server is the authority for the project's current documents; Studio sends edits, receives numbered results, and keeps local work when the connection is unavailable.

<Callout type="info">
NarraLeaf Team 1.0 is a stable release. The web console is a beta: its main project, review and administration flows are usable, and individual screens can still change.
</Callout>

## What a server holds

| Content | Description |
| --- | --- |
| Projects | A repository, a registry row, and the current state of each team document. |
| Versions | Any two revisions compare; restoring one creates another version and is credited to the author. |
| Roles and areas | Owner, editor, reviewer and viewer, with editor areas for story, characters, assets, UI, localization and config. |
| Collaboration | Row comments, suggested edits, to-dos, reviews, approvals, asset locks, discussions, notifications and presence. |
| Production | Builds, share links, localization, glossary, voice, roadmaps, templates and webhooks. |
| Administration | Accounts, policies, signing keys, storage, backups, archive, audit filters and access decisions. |

## What Studio 2.0 adds

- Browser sign-in with OAuth and PKCE, plus a device flow for a machine without a browser
- The signed-in account in the title bar, including while the server is away
- A Team history rail, file conflicts, reconnecting and offline replay
- A round-trip indicator for the server in the status bar
- Project roles and area permissions known before an edit
- Permission templates and access requests
- `narraleaf://team/connect` links that fill in the Add Server dialog

## The web console

`https://<server>:54080/console/` lists projects as the server holds them, reads files and versions, and handles comments, reviews, to-dos and administration in English, Chinese and Japanese, on a desktop or a phone.

The console never becomes a second editor for project content. Content changes in Studio; the console reads it and records the work around it.
