---
title: NarraLeaf Team
description: Studio 2.0 のチームプロジェクト、バージョン、役割、共同作業の記録を保持するセルフホスト型サーバー
---

NarraLeaf Team は組織が自分で運用するサーバーです。チームのプロジェクトを保持し、各プロジェクトへのアクセスを決め、ドキュメントとバージョンを保存し、Studio とは別に Web コンソールを提供します。

Studio 2.0 はチームプロジェクトとローカルプロジェクトを別に扱います。サーバーがチームプロジェクトの現在のドキュメントの正本であり、Studio は変更を送り、番号付けされた結果を受け取り、接続できない間もローカルの作業を保持します。

<Callout type="info">
NarraLeaf Team 1.0 は安定版です。Web コンソールはベータ扱いで、プロジェクト、レビュー、管理の主要な流れは利用できますが、個々の画面は変更されることがあります。
</Callout>

## サーバーが保持するもの

| 内容 | 説明 |
| --- | --- |
| プロジェクト | リポジトリ、登録行、各チームドキュメントの現在状態 |
| バージョン | 任意の 2 つのリビジョンを比較でき、復元すると新しいバージョンになり、実際に行った人の名義で記録されます |
| 役割と領域 | 所有者、編集者、レビュー担当、閲覧者。編集者はストーリー、キャラクター、アセット、UI、ローカライズ、設定の領域に制限できます |
| 共同作業 | 行コメント、変更提案、ToDo、レビュー、承認、アセットロック、ディスカッション、通知、プレゼンス |
| 制作 | ビルド、共有リンク、ローカライズ、用語集、ボイス、ロードマップ、テンプレート、Webhook |
| 管理 | アカウント、ポリシー、署名キー、ストレージ、バックアップ、アーカイブ、監査フィルター、アクセス判断 |

## Studio 2.0 が加える接続機能

- OAuth と PKCE によるブラウザサインイン、ブラウザのないマシン向けのデバイスフロー
- サーバーが応答しない間もタイトルバーに残るサインイン済みアカウント
- Team 履歴レール、ファイル競合、再接続、オフライン変更の再送
- ステータスバーでのサーバーとの往復表示
- 編集前に分かるプロジェクトの役割と領域権限
- 権限テンプレートとアクセス申請
- アドレスを入力済みで Add Server ダイアログを開く `narraleaf://team/connect` リンク

## Web コンソール

`https://<サーバー>:54080/console/` は、サーバーが保持する形でプロジェクトを一覧し、ファイルとバージョンを読み、コメント、レビュー、ToDo、管理を扱います。英語、中国語、日本語に対応し、デスクトップでもスマートフォンでも使えます。

コンソールがプロジェクト内容の第二のエディターになることはありません。内容は Studio で変更し、コンソールはそれを読み、周辺の作業を記録します。
