---

NarraLeaf Team 是由团队自己运行的一台服务器。它保存团队项目，决定谁能访问每个项目，保留文档与版本，并在 Studio 之外提供自己的 Web 控制台。

Studio 2.0 把团队工程与本机工程分开处理。服务器是团队工程当前文档的权威来源；Studio 发送修改、接收编号后的结果，并在连接不可用时保留本机工作。

<Callout type="info">
NarraLeaf Team 1.0 是稳定版本。Web 控制台标为 beta：项目、审阅和管理的主要流程已经可用，个别页面仍可能调整。
</Callout>

## 服务器保存什么

| 内容 | 说明 |
| --- | --- |
| 项目 | 仓库、注册表中的一行，以及每份团队文档的当前状态 |
| 版本 | 任意两个修订可以比较；恢复某个修订会产生新的版本，并记在实际完成它的人名下 |
| 角色与区域 | 所有者、编辑者、审阅者与查看者；编辑者可以按剧情、角色、资产、界面、本地化或配置分区授权 |
| 协作 | 行批注、建议修改、待办、审阅、批准、资产锁、讨论、通知与在场状态 |
| 制作 | 构建、分享链接、本地化、词汇表、配音、路线图、模板与 Webhook |
| 管理 | 账号、策略、签名密钥、存储、备份、归档、审计筛选与访问决定 |

## Studio 2.0 新增的连接能力

- 使用 OAuth 与 PKCE 的浏览器登录，以及无浏览器机器使用的设备码流程
- 标题栏显示当前 Team 账号，服务器离线时仍会保留
- Team 历史轨、文件冲突、重新连接与离线修改重放
- 状态栏显示与服务器的往返状态
- 修改前即可知道项目角色与区域权限
- 权限模板与访问申请
- `narraleaf://team/connect` 链接会打开添加服务器窗口并填好地址

## Web 控制台

`https://<服务器>:54080/console/` 按服务器保存的内容列出项目，读取文件与版本，并处理批注、审阅、待办和管理事务；支持英文、中文和日文，也支持桌面与手机浏览器。

控制台不会成为第二个编辑项目内容的地方。内容在 Studio 中修改；控制台负责阅读内容并记录围绕它的工作。
